
# NYC 311 Service Request Analysis

## 1. Project Overview

This project analyses real public service requests submitted through NYC 311, New York City's non-emergency service request system.

The objective is to investigate service request patterns, evaluate resolution performance, identify operational trends, and discover potential areas for improvement.

The analysis will use publicly available data from NYC Open Data.

## 2. Business Objectives

- Understand the volume and distribution of service requests.
- Identify the most frequently reported problems.
- Evaluate service request resolution times.
- Compare performance across agencies and boroughs.
- Identify seasonal and geographical patterns.
- Investigate unresolved requests and potential operational bottlenecks.

## 3. Research Questions

1. How does the volume of service requests change over time?
2. Which types of problems generate the most requests?
3. Which agencies receive the highest number of requests?
4. What is the average and median resolution time?
5. Which categories take the longest to resolve?
6. How does resolution performance vary across boroughs?
7. What proportion of requests remain open?
8. Are there seasonal patterns in service requests?

## 4. Data Source

NYC 311 Service Requests from 2020 to Present.

Source: NYC Open Data  
https://data.cityofnewyork.us/

The dataset contains real public service request records.

Due to its large size, the project will use the NYC Open Data API to retrieve a manageable selection of records.

The final date range and sample size will be determined during data exploration.
